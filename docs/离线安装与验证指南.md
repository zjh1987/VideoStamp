# VideoStamp 离线安装与验证指南

适用版本：MVP（VideoStamp.exe / VideoStampCLI.exe）
适用环境：Windows 10 / 11（64 位），**全程无需联网、无需安装任何运行库、无需管理员权限**

---

## 1. 安装包内容

交付物为 `VideoStamp` 文件夹（约 301 MB），结构如下：

```
VideoStamp\                     ← 整个文件夹就是要拷贝的全部内容
├─ VideoStamp.exe               ← 图形界面主程序（日常用这个）
├─ VideoStampCLI.exe            ← 命令行批量工具（可选）
├─ _internal\                   ← 程序内部依赖（PySide6、Qt、Python 运行库等）
│   └─ vendor\ffmpeg\
│       ├─ ffmpeg.exe            ← 转码引擎
│       └─ ffprobe.exe           ← 视频信息探测
└─ config\                      ← 便携配置目录（首次正常关闭后自动生成 settings.ini）
```

要点：

- **绿色免安装**：把整个 `VideoStamp` 文件夹用 U 盘/局域网/任何方式拷到目标电脑任意位置（建议非系统盘，如 `D:\VideoStamp`）即完成"安装"。
- **文件夹必须整体拷贝**，`_internal` 不能拆分或单独移动。
- 所有依赖（Qt、Python 运行库、FFmpeg）均已内置，目标电脑**不需要**装 Python、FFmpeg 或 VC++ 运行库。
- 配置保存在程序目录内的 `config\settings.ini`，不写注册表；删除该文件即可恢复默认设置。
- 如需升级 FFmpeg，只要用新的 `ffmpeg.exe` / `ffprobe.exe` 覆盖 `_internal\vendor\ffmpeg\` 下的同名文件（或在 exe 旁新建 `vendor\ffmpeg\` 文件夹放入，会优先使用）。

## 2. 安装步骤（离线机器）

1. 在有网的机器上确认拿到完整的 `VideoStamp` 文件夹（核对大小约 301 MB）。
2. 用 U 盘等离线介质将整个文件夹复制到目标电脑，例如 `D:\VideoStamp`。
3. 进入文件夹，双击 `VideoStamp.exe`。
4. **首次运行如弹出 Windows SmartScreen 蓝色提示**（程序未签名，属正常现象）：
   点击"更多信息" → "仍要运行"。此提示只在首次出现。

## 3. 安装后验证（建议逐项执行）

### 3.1 基础验证：程序能启动

双击 `VideoStamp.exe`，应出现标题为 **VideoStamp - 视频批量加时间戳** 的主窗口。
若 5 秒内弹出错误对话框（如"未找到 ffmpeg/ffprobe"），见第 4 节排查。

### 3.2 功能验证：真实打戳一个视频

1. 准备一段任意短视频（手机拍的几秒即可）。
2. 将其拖入主窗口文件列表（或点"添加文件"）。
3. 时间源保持默认"视频元数据（推荐）"，直接点"开始"。
4. 预期结果：
   - 日志区依次出现 `[探测] → [时间] → [编码] → [执行] → [完成]`；
   - 源视频所在目录生成 `stamped\` 子文件夹，内有 `原名_stamped.mp4`；
   - 播放输出文件，画面上应叠加有日期时间水印且随时间走动。
5. 抽帧确认（可选，在文件所在目录打开命令行执行）：

   ```
   VideoStamp\_internal\vendor\ffmpeg\ffmpeg.exe -ss 1 -i stamped\原名_stamped.mp4 -frames:v 1 check.png
   ```

   打开 `check.png`，肉眼确认时间戳文字清晰可见。

### 3.3 命令行验证（可选）

在 `VideoStamp` 文件夹地址栏输入 `cmd` 回车，执行：

```
VideoStampCLI.exe --dry-run --input "C:\path\to\video.mp4" --time-mode manual --start "2026-09-11 14:30:00"
```

预期输出一行 `[计划] xxx.mp4 → xxx_stamped.mp4 起始=2026-09-11 14:30:00 (手动指定)`，退出码为 0，说明引擎链路完好。

### 3.4 二次启动验证（回归项）

正常关闭程序（右上角 ×）后再次双击 `VideoStamp.exe`。
此项专门验证设置读写：若能正常打开且界面参数与上次一致，说明 `config\settings.ini` 读写正常。

## 4. 常见问题排查

| 现象 | 原因与处理 |
| --- | --- |
| 界面显示"未检测到可用 GPU 编码" | 显卡驱动过旧（NVIDIA 需 610.00+，约 2025 年后的驱动）。更新显卡驱动后重启程序即可启用；否则自动用 CPU，不影响打戳，只是速度慢 |
| SmartScreen 拦截 | 未签名程序的正常提示，"更多信息 → 仍要运行" |
| 提示"未找到 ffmpeg/ffprobe" | `_internal\vendor\ffmpeg\` 下的两个 exe 缺失或被杀毒软件隔离；从备份恢复，或自行下载 x64 版 ffmpeg.exe/ffprobe.exe 放入该目录（也可放 exe 旁的 `vendor\ffmpeg\`） |
| 双击后窗口一闪而过 / 无响应 | 杀毒软件拦截。将 `VideoStamp` 文件夹加入白名单后重试 |
| 界面参数错乱 / 启动报设置相关错误 | 关闭程序，删除 `config\settings.ini` 后重启（恢复默认设置，不影响任何视频） |
| 时间戳时间不对 | 换时间源试试：元数据缺失会回退到"文件创建时间"；拷贝过的文件建议用"手动指定"起始时间 |
| 报错"模板含不支持的字面冒号" | 时间格式模板里不要手写 `%H:%M:%S` 以外的冒号组合；用 `%T`（时:分:秒）或 `%R`（时:分） |

## 5. 日常使用速查

- **支持格式**：mp4 / mov / avi / mkv / ts / m2ts / mts / flv / webm / wmv / mpg / mpeg / m4v / 3gp / mxf / vob
- **输出规格与源一致**：自动沿用源视频的编码格式（H.264 源 → H.264 输出；HEVC/H.265 源 → HEVC 输出）、分辨率、帧率、时长；容器默认与源相同（个别不兼容的容器如 webm/vob 自动改用 mp4）。10bit HEVC 源保留 10bit 位深
- **硬件加速**：自动探测 NVIDIA NVENC / Intel QSV / AMD AMF，可用则优先使用；探测或编码失败自动回退 CPU（x264/x265），界面会显示当前检测结果。探测不到 GPU 编码通常是显卡驱动过旧，更新驱动即可
- **输出位置**：默认输出到源文件旁的 `stamped\` 文件夹，文件名 = 原名 + `_stamped`；已存在同名输出会自动跳过（可在界面勾选覆盖）
- **四种时间源**：
  - 视频元数据（推荐）：读取拍摄设备写入的 creation_time，缺失时回退文件创建时间
  - 文件创建时间：直接取 Windows 文件属性里的创建时间
  - 手动指定：自己填起始时间，适合时间已被破坏的文件
  - 文件名正则：从文件名提取，如 `VID20260911_143005.mp4` 配
    `VID(?P<Y>\d{4})(?P<m>\d{2})(?P<d>\d{2})_(?P<H>\d{2})(?P<M>\d{2})(?P<S>\d{2})`
    （分组 Y/m/d/H/M/S 必须从 Y 开始连续出现）
- **批量**：直接把整个文件夹拖进窗口即可，列表顺序即打戳顺序（可用"上移/下移"调整）
- **顺序连续时间戳（批量录制推荐）**：默认勾选"按顺序连续排列时间戳"。只需在"起始时间"里填**第一个视频**的开始时间，后续视频自动接续前一个的结束时间（开始+时长），依次连续排列；表格实时显示每个视频的开始/结束时间和总时长。双击列表中某一行可手动微调单个文件，其后的视频会自动顺延；取消勾选则恢复按"时间源"逐文件取时间
- **时长异常提示**：若某视频损坏导致无法读取时长，列表"备注"列会显示"⚠ 时长未知"并弹窗说明，连续排列在该文件处断开，其后视频回退使用全局时间源
- **逐文件手动微调**：双击列表中某一行（或选中后点"设置选中文件起始时间"，支持多选），可指定该文件的打戳起始时间；备注列显示"手动设定"，"清除手动时间"可恢复自动计算
- **样式预览**：点"预览选中文件样式"可查看该视频中间帧的打戳效果（字体/位置/颜色/底框），确认无误后再批量处理
- **悬浮说明**：把鼠标停在任意参数或按钮上 1 秒，会显示该项的作用与填写示例
- **结果清单**：处理完可导出 CSV 记录每个文件的成功/跳过/失败与时间来源
